# **Kanbas - Frontend**

**Kanbas** is a Learning Management System (LMS) inspired by Canvas, developed as part of the **CS5610 Web Development** course at Northeastern University. This repository contains the **frontend** of the application, built using **React** and **JavaScript**. The app is hosted on **Netlify**.

For the **backend repository**, visit: [Backend Repository](https://github.com/iamkaylaliu/kanbas-node-server-app)  

---

### **Key Features**
- Modern, user-friendly interface inspired by Canvas LMS.
- Seamless integration with the backend for data handling.
- Designed to support both students and instructors with essential LMS functionalities.
- Key modules include navigation, account, dashboard, courses, and database.

---

### **Technologies Used**
- **Frontend**: React, JavaScript, HTML, CSS
- **Hosting**: [Netlify](https://www.netlify.com/)

---

### **How to Run Locally**
1. **Clone the repository**:
   ```bash
   git clone https://github.com/iamkaylaliu/kanbas-react-web-app.git
   ```
2. **Navigate to the project directory**:
   ```bash
   cd kanbas-react-web-app
   ```
3. **Install dependencies**:
   ```bash
   npm install
   ```
4. **Start the development server**:
   ```bash
   npm start
   ```
5. **Open your browser and visit**:
   ```bash
   http://localhost:3000
   ```
